# `sigil`

## Usage

```
sigil <command>
```

Lists the commands under it and takes no action of its own.

## Subcommands

| Command | Description |
| --- | --- |
| [`sigil add`](add.md) | Copy a component into your app, so you own it |
| [`sigil build`](build.md) | Build an app into a bundle that depends on nothing |
| [`sigil check`](check.md) | Check an app without building it |
| [`sigil new`](new.md) | Create a new app |
| [`sigil package`](package.md) | Build an app and compile it into a single executable |
| [`sigil reference`](reference.md) | Write a markdown command reference, or a snapshot of the command surface |
